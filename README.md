# DataNest-Supository

Canonical Resonance monorepo candidate for DataNest governance, Resonance Hub runtime/commercial delivery, RONSAS sovereign operations, Open Nova development tooling, and RCGF constitutional governance.

## Authority boundaries

- `apps/datanest` — governance, certified knowledge, audit and transparency control plane.
- `apps/hub` — runtime/commercial/customer front door.
- `platform/ronsas` — sovereign orchestration, topology, workers, recovery and bounded services.
- `platform/open-nova` — provider-neutral/zero-credit development and migration platform.
- `governance/rcgf` — constitutional governance framework.
- `packages` — shared contracts/schemas/policy/UI only after governed extraction.
- `ops` — canonical node, service, deployment and validation controls.
- `evidence` — migration, audit, certification and release evidence; never secrets or production data.

## Consolidation status

This repository is an isolated recovery/consolidation candidate. Original source repositories remain unchanged. Promotion to a new forge is blocked until source reconciliation, security checks, component builds, cross-system validation and human governance approval complete.
