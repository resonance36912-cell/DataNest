# BOTSQUAD Tree

**BOTSQUAD** is DataNest's AI-only specialist tree for optimization, expansion, responsible business growth, UX ease-of-use, UI evolution, function evolution, integrations, quality observation, and environment translation.

Each specialist writes only to its dedicated `automation/botsquad/*` branch. The orchestrator combines specialist outputs into non-authorizing feeds for DataNest and Mirror.

BOTSQUAD may propose, analyze, prioritize, and publish evidence-backed recommendations. It cannot approve, merge, deploy canonical production, alter governance, or make commercial commitments. Canonical source changes remain subject to DataNest Boundaries, Audit Optimizer evidence, and human review.
