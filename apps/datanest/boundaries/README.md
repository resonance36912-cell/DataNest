# Boundaries Tree

The **Boundaries** tree is the canonical DataNest acceptance and tolerance assessor. It converts DataNest human-AI principles into explicit, reviewable repository criteria without allowing an automated system to become the moral or production authority.

Boundaries evaluates change impact across production authority, privacy/secrets, destructive maintenance, AI/learning, data changes, repository synchronization, testing evidence, and human authorization.

## Semantics

- A **hard boundary** is a machine-verifiable invariant that must not be crossed.
- A **tolerance** describes how much uncertainty or automated action is accepted before human review is required.
- **Acceptance criteria** describe the evidence expected for a class of change.
- Passing Boundaries is evidence only. It is never production authorization or certification.
- FREETREE is outside DataNest synchronization and policy authority. Boundaries may document that isolation, but it must not ingest, govern, or synchronize FREETREE development.
