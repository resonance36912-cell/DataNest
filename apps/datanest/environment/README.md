# ENVIRONMENT Tree

**ENVIRONMENT** is the meta-tree that evaluates the operating conditions required by DataNest, Mirror, Knowledge, Boundaries, BOTSQUAD, Resonance Forge, and the isolated FREETREE.

It assesses source control, runtime, CI, delivery, backend, AI inference, registry, recovery, dependencies, branch hygiene, and evidence/observability. It publishes compatibility and adaptation feeds and may automatically refresh only generated metadata or other deterministic non-authorizing state.

Changes to runtimes, dependencies, providers, permissions, production workflows, Forge authority, backends, or credentials require human review. FREETREE remains isolated and receives no automatic synchronization.
