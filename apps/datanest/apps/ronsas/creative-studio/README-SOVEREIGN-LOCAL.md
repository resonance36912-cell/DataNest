# Resonance Creative Studio — Sovereign Local v0.1

Run with the Open Nova installer supplied with this package. The local preview is registered at:

`http://localhost:3201/studio`

This build is designed to remain useful with network access unavailable after npm dependencies have been installed. Poster generation in v0.1 is deterministic and on-device; it does not call an AI provider.
