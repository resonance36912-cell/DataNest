# SUGGESTER Tree

**SUGGESTER** continuously turns GUARDIAN health/drift, Knowledge learning, ENVIRONMENT compatibility, ENFORCER security state, BOTSQUAD recommendations, and CONDUCTOR timing state into traceable optimization suggestions.

Only allowlisted reversible actions become autonomous-update commands. Behavioral source changes, dependency/runtime/provider changes, governance changes, UI/function changes, and business/product changes remain review-required.

Each feed includes source timestamps, content digests, the exact checked-out SHA, and the triggering CONDUCTOR run when present. Missing, stale, future-dated or authority-changing inputs remain visible as evidence-repair suggestions. Commands are emitted only when all six sources validate, ENFORCER passes, ENVIRONMENT is compatible, GUARDIAN is healthy or healing, and CONDUCTOR reports a synchronized graph for the same source revision.

Branch cleanup is live-revalidated by the existing cleaner. The source-normalization command creates a review PR and never edits canonical main directly. Identical suggestions retain their fingerprints across pulses; changed branch names, refinements or source revisions produce new fingerprints. Scheduled analysis every 15 minutes continues to report problems even when CONDUCTOR is waiting on a dependency.
