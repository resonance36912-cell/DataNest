# DataNest AI Founder Baseline — 2026-09-28

DataNest production has a founder-authorized certified-memory baseline in its private governed data store. The baseline is intentionally not embedded in this public repository.

The baseline covers platform authority, product ecosystem, AI principles, governed learning, memory policy, privacy boundaries, commercial direction, engineering governance, infrastructure roles, and model portability.

## Compute independence

DataNest is the authority and must remain fully cloud-operational without any specific workstation.

- Supabase provides governed authentication, data, memory, policy and AI-function services.
- The DataNest web delivery surface remains independently available.
- Open-source/open-weight inference is provider-agnostic and may use any approved HTTPS OpenAI-compatible endpoint.
- Dropbox is a recoverable backup/evidence mirror, not execution authority or source authority.
- Ealiophin is an optional sovereign compute node for local inference, heavy processing, private workloads and failover. DataNest must continue operating when Ealiophin is offline, replaced or retired.
- Additional compute nodes may be registered later without changing DataNest identity, memory, policy or audit semantics.

Future user interactions remain provisional until they pass the existing DataNest validation and certification pipeline. The model layer stays provider-agnostic so a larger open-source/open-weight model can replace or augment the current runtime without changing the governed-memory contract.
