# RONS Sovereign Codebase

Consolidated source repository for Resonance Open Nova Sovereign (RONS).

This repository was assembled from the sanitized production audit snapshot plus the recovered recent integration patches. Runtime secrets, local `.env` files, private keys, dependencies, caches, generated build output, and Git metadata were intentionally excluded.

Primary application source is at the repository root. Recovered recent integration material is under `recovered-integrations/`.
