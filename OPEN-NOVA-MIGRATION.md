# Creative Studio — Sovereign Local v0.1

This migration is a **local preview**, not a production cutover.

## Local in v0.1
- React/Vite Creative Studio UI
- Local session identity (no hosted authentication)
- Local browser persistence for table-like application data
- Local browser storage for small uploaded assets
- Local project draft/snapshot fallback already present in the original app
- Deterministic local creative-brief analysis
- Deterministic local SVG poster generation (2 variants)
- Existing editing/layout UI that does not require hosted services

## Deliberately disabled / held for later sovereign replacement
- Hosted Supabase database/auth/storage
- Supabase Edge Functions
- Lovable AI / Lovable Cloud auth
- Hub entitlement/payment checks
- Remote URL scraping and Firecrawl enrichment
- Hosted AI poster/image editing
- Hosted cinematic/video generation
- Hosted logo/voice/jingle generation

The original `.env` file, Supabase backend tree, and Lovable metadata are not included in this package.
