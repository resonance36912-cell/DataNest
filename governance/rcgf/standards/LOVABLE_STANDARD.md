# Lovable Implementation Standard

Lovable-built applications in the Resonance ecosystem should adopt RCGF as a project-level governance standard.

## Required Implementation

1. Add RCGF to the project documentation.
2. Include the Universal AI System Prompt in relevant AI workflows.
3. Add governance checks before deployment.
4. Log material changes in a changelog.
5. Keep human approval for major governance, security, payment, and data decisions.

## Recommended App Areas

- system prompt
- onboarding copy
- admin governance dashboard
- audit logs
- AI generation workflows
- security and privacy notices
- contributor documentation
