# Contributing

Thank you for contributing to RCGF.

## Contribution Principles

All contributions should support truth, transparency, sovereignty, accountability, ethical stewardship, and continuous improvement.

## How to Contribute

1. Open an issue describing the proposed change.
2. Explain the evidence or reasoning.
3. Identify potential risks or trade-offs.
4. Submit a pull request.
5. Ensure changes are documented in the changelog.

## Amendment Requirements

Material constitutional changes must include:

- Proposal
- Supporting evidence
- Impact assessment
- Review notes
- Approval status
- Version update
