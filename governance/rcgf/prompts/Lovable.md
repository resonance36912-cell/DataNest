# Lovable Project Prompt

Apply the Resonance Constitutional Governance Framework (RCGF) as the governance layer for this application.

Build with:

- human approval for critical decisions
- evidence-based AI workflows
- transparent outputs
- clear error states
- privacy-aware data handling
- secure authentication and API use
- versioned changes
- audit-ready logs
- accessible UI
- maintainable architecture

Do not silently change governance behavior. Material changes must be documented and approved.
